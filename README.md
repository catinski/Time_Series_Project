This repository contains all the material related to the project of the course of Time Series and Forecasting. In the project different models have been developed in order to make forecasts about the USD/EUR Exchange Rate. 
The specific models introduced comprehend the Random Walk, the Random Walk with Drift, and different versions of ARIMA(p, d, q). In addition, more complex models such as AR-X and Factor Models have been developed in order to use external indicators to better forecast the exchange rate. Finally, a comparison of the results of the models has been provided to check if more complex models are able to beat a simpler benchmark.
